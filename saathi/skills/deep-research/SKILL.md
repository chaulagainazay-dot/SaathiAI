# Deep Research Skill

## Available internet tools
All tools are non-privileged — call freely, no voice gate needed.

| Tool | Use for | Example |
|------|---------|---------|
| `web_search` | Quick facts, news, current info | `web_search("IELTS 2025 changes")` |
| `read_webpage` | Read full article / documentation | `read_webpage("https://...")` |
| `youtube_info` | Get video title, description, auto-subs | `youtube_info("https://youtube.com/...")` |
| `youtube_subtitles` | Full transcript of a video | `youtube_subtitles("https://...", "en")` |
| `github_repo` | Repo overview + README | `github_repo("owner/repo")` |
| `rss_feed` | Latest posts from a blog or news site | `rss_feed("https://blog.example.com/feed")` |
| `bilibili_search` | Chinese video platform search | `bilibili_search("IELTS 雅思")` |
| `reach_doctor` | Check which internet channels are active | `reach_doctor()` |

## Research workflow
1. **Start with `web_search`** — quick 5-result overview
2. **Deep-dive with `read_webpage`** on the most relevant result
3. **Cross-check with YouTube** if topic benefits from video explainers
4. **GitHub repos** — always check for new tools/libraries Ajay might use
5. **Summarize findings** in 3-5 bullet points; link sources

## Research for pielts content
When researching an IELTS topic for content creation:
1. Search for recent IELTS exam questions on this topic
2. Find common student mistakes (forums, YouTube comments)
3. Find the most-searched vocabulary for this topic
4. Structure findings into a Facebook post or YouTube script

## Quality rules
- Always cite the source URL
- Flag if info might be outdated (check publish date)
- For GitHub repos: note stars, last commit date, whether actively maintained
- Never present scraped content as Baadar's own — attribute it
