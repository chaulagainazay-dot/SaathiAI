# IELTS Teaching Skill

## Exam structure
| Module | Tasks | Time |
|--------|-------|------|
| Listening | 4 sections, 40 questions | 30 min + 10 transfer |
| Reading (Academic) | 3 passages, 40 questions | 60 min |
| Writing (Academic) | Task 1 (graph/chart, 150w) + Task 2 (essay, 250w) | 60 min |
| Speaking | Part 1 (intro), Part 2 (cue card), Part 3 (discussion) | 11-14 min |

## Band descriptors (simplified)
| Band | Description |
|------|-------------|
| 9 | Expert — full operational command |
| 8 | Very good — occasional inaccuracies |
| 7 | Good — handles complex language, some errors |
| 6 | Competent — effective but with mistakes |
| 5 | Modest — partial command, frequent errors |

## Writing Task 2 structure (essay)
```
Introduction (2-3 sentences):
  - Paraphrase the question
  - State your position / overview

Body Paragraph 1 (5-7 sentences):
  - Topic sentence (main point)
  - Explanation
  - Example / evidence
  - Link back to question

Body Paragraph 2 (5-7 sentences):
  - Same structure as Body 1

Conclusion (2-3 sentences):
  - Restate position
  - Summary of main points
  - (optional) future implication
```

## Writing Task 1 structure (Academic — graph/chart)
```
Introduction: Paraphrase what the graph shows
Overview: 2 main trends (no numbers here)
Detail Para 1: Highest values, key comparisons (with data)
Detail Para 2: Lower values, exceptions, trends (with data)
```

## Common student mistakes by skill
### Writing
- Using "I think" instead of "It is argued that / It can be seen that"
- Repeating vocabulary instead of using synonyms
- Not supporting claims with examples
- Too short (under 250 words for Task 2)

### Speaking
- Giving one-word answers
- Not extending answers naturally
- Memorized responses (examiner detects and penalizes)
- Using "because" without explaining

### Vocabulary boosters (Task 2)
- "a significant increase/decrease" not "a big rise"
- "approximately / roughly / around" for estimates
- "whereas / while / in contrast" for comparisons
- "consequently / as a result / therefore" for results
