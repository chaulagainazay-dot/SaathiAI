# Background music (bring your own)

Drop royalty-free / CC0 tracks here, named by mood so the selector can pick one:

    calm.mp3   mystery.mp3   energetic.mp3   emotional.mp3

The Creative Director sets a mood; `saathi.tools.music.select(mood)` maps it to a
file. If this folder has no audio, videos render without music (no error).

We never bundle or download copyrighted audio. Good sources: YouTube Audio
Library, Pixabay Music, Free Music Archive (CC0 / CC-BY with attribution).
