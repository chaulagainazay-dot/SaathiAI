# PROPOSAL_LIFECYCLE

Status vocabulary:

DRAFT → READY_FOR_RISK → READY_FOR_APPROVAL | RISK_BLOCKED | RISK_WARN | DATA_INSUFFICIENT
→ EXPIRED | SUPERSEDED | STALE_PROPOSAL | REJECTED | APPROVED

- APPROVED is set by approval system only (engine never auto-approves)
- No execution statuses live here
- Transitions recorded in `pc_transitions` audit table
