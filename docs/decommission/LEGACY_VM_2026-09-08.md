## Staged decommission — operator steps

Run from a machine holding the VM's SSH key. Levels are ordered so each is
reversible before the next.

```bash
# LEVEL 1 — stop serving, keep everything installed
sudo systemctl stop saathi-api saathi-ui

# LEVEL 2 — stop it coming back on boot
sudo systemctl disable saathi-api saathi-ui

# LEVEL 3 — stop the public hostname routing to the application
sudo systemctl stop caddy && sudo systemctl disable caddy

# LEVEL 4 — power off, storage preserved (Oracle Cloud console, or:)
sudo shutdown -h now
```

**Do not proceed to instance/boot-volume termination** until the connector
accounts above are re-authorised locally and the archive has been reviewed.
