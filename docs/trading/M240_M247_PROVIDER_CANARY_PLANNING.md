## Objective

Convert the generic read-only integration framework (M216–M239) into a **provider-specific, evidence-backed canary proposal** ready for human owner review — without connectivity, credentials, or production authority.

## Provider-selection method

Structured evaluation across eligibility, security, API quality, operational suitability, and commercial/product fit. Each score records evidence, confidence, uncertainty, disqualifying issues, and unresolved questions. Missing evidence is never hidden behind a bare number.
