## Clean-clone methodology

1. **Stage A — clean worktree:** `git worktree add --detach` without node_modules, venv, `.env`, or local DBs; import + source-audit smoke.
2. **Stage B — clean clone:** `git clone --local` from committed objects; checkout SHA; import + source-audit smoke.
3. Full pytest / frontend / production build / browser cert run in the primary tree and are linked via provenance; clone stage records explicit machine-resource limitations.
