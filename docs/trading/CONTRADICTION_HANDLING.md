# M62.3 — Contradiction Handling

First-class stage. Types: DIRECT_CONFLICT, NUMERICAL_CONFLICT, TEMPORAL_CONFLICT,
SCOPE_CONFLICT, DEFINITION_CONFLICT, SOURCE_REVISION, FORECAST_DISAGREEMENT. Both
conflicting claims are preserved (never discarded to favour a conclusion). Severity
recorded; same-date high-materiality numeric conflicts are critical and surface in the
challenge → block publication until resolved. Temporal (different-dated) numeric
differences are classified SOURCE_REVISION.
