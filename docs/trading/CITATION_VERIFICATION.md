# M62.3 — Citation Verification

Machine-checkable: a citation verifies only when the source exists, the source hash
matches (detecting supersession/tampering), the locator resolves (line:N / para:N /
field:NAME / row:N), and the citation is same-tenant. Failures → Verification.FAILED.
A FACT/CALCULATION claim without a verified citation is a critical challenge finding
and blocks publication. Fabricated or unresolvable locators fail (certified).
