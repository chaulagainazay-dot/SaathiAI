# Private Alpha Limitations

1. Local-only single machine
2. Not production-authorized
3. Public exposure not authorized
4. No live payments
5. No production Firebase
6. No paid AI provider activation during first-run
7. Automations opt-in only; limited action catalog
8. Trading Guardian advisory / unengaged
9. No multi-host / multi-device sync
10. No public marketplace
11. Owner-managed backups
12. No guaranteed uptime
13. Synthetic/demo data for certification journeys
14. Upgrade certification limited to local/synthetic fixtures (no remote auto-update)
15. Browser certification depends on local services being available for full E2E

## Production blockers (non-exhaustive)

- Multi-tenant SaaS hardening
- Public exposure controls and CDN/edge
- Paid provider billing and secrets management
- Live payment + production Firebase certifications
- Formal uptime/SLA operations
- Full accessibility audit with assistive tech users
- Remote update channel with code signing
