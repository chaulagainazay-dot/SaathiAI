## Design principle (standing)

Reuse **ideas and isolated components**, not whole applications. Every external capability
is wrapped behind one of the platform's abstractions (Model Router, Browser Service, Tool
Registry, Voice Engine); the rest of SaathiAI stays unaware of which underlying project
provides the capability.

## Two-abstraction rule (recorded from Phase 1.1)

- **`router`** — stateless capability calls (`generate/embed/vision/classify/reason`). Used by every department.
- **`agent_router`** (future) — stateful runtimes (conversation, tool-use, streaming, computer-use, voice sessions) where Claude / GPT Responses / Gemini Live diverge. The Voice OS plugs in here; `agent.py` + multimodal eval stay native until then.
