# UX_ARCHITECTURE

Four modes over one system state:

```text
COMMAND | AGENTS | INVESTMENTS | EVIDENCE
```

Plus always-on:

```text
Authority strip · Voice/Saathi state · Attention · PAPER labels
```

## Principles

1. One system, four lenses.
2. Decision speed > decoration.
3. Truth contracts > visual flourish.
4. Voice is navigation, not a gadget.
5. Risk and portfolio use canonical field names.
6. Mobile is Saathi-first, not shrunk topology.
