# REFERENCE_VIDEO_ANALYSIS

Binary video assets were not present in the workspace for this run. Analysis is derived from the UI-NEXT-2 mission brief (three command-center style references as **inspiration, not cloning**) plus institutional cockpit patterns.

## Patterns to ADAPT

| Pattern | Why |
| --- | --- |
| Multi-panel command density | Decision speed for operators |
| Central focal assistant | Voice + context without cartoon takeover |
| Bounded agent topology | Mission comprehension without infinite graphs |
| Persistent status strip | TG / paper / health always visible |
| Attention queue prominence | Approvals and blockers first |
| Calm dark graphite surfaces | Trust + long-session readability |
| Numeric tabular scanning | Portfolio/risk workstation |

## Patterns to REJECT

| Pattern | Why |
| --- | --- |
| Neon cyberpunk glows | Undermines institutional trust |
| Crypto casino charts / confetti P&L | Wrong product category |
| Full-screen 3D worlds as default OS | Performance + 8 GB host risk |
| Decorative fake live data | Violates authority / DEMO honesty |
| Infinite force-directed agent graphs | Navigation chaos |
| Motion as constant ambient GPU load | Latency + battery |

## Separation of concerns

Videos inspire **hierarchy and presence**. SaathiOS owns **truth contracts** (ledger, risk, TG, voice session).
